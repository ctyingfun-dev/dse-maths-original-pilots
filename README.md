重新產生 PDF：修改卷一題目或列印樣式後，執行 `node build-paper1-pdf.cjs`。此指令使用 Playwright 及本機 Microsoft Edge，檢查每題的作答空間、內容寬度及解答隱藏狀態，再輸出 A4 PDF。

2025 PDF 指令：`node build-paper1-pdf.cjs 2025 1` 及 `node build-paper1-pdf.cjs 2025 2`。輸出位於 `output/pdf/`，檔名包含 `2025`，不覆蓋 2026 PDF。

瀏覽器測試及 PDF 工具需要 Playwright 和 Microsoft Edge；可用 `npm install --no-save --package-lock=false playwright` 安裝測試依賴。`smoke-test.cjs` 預設連線本機 4284 埠，可用 `PREVIEW_URL` 指定另一個預覽網址。數學驗算 `verify-2026.cjs` 只需要 Node.js。

檢查：`node verify-2026.cjs` 驗證64題的結構、卷二答案鍵、64項逐題獨立計算（卷一19題及卷二45題）、分式語意及卷一分題配分；`node smoke-test.cjs` 在1440、1004、390、320 px測試兩卷題目、所有卷一評分參考及45題卷二批改解答的排版、PDF下載、圖題對照、表格、分題配分及提示／收藏保存，另檢查換題進度遷移、技巧站、重新整理、計時、備份、搜尋內操練和錯題重做。

用語檢查：`node verify-notation.cjs` 核對四份題庫、兩份課題摘要及兩個數學排版器，防止舊坐標用語、文字形式的恆等關係及單字元二分之一再次出現在顯示內容中；保留 t、z 等實際變數的軸及截距名稱。

版面及配色檢查：`node qa-palette.cjs` 測試兩年份、兩試卷的八個頁面，在1440、1004、390、320像素寬度檢查四項工具連結常駐可見、全部導覽連結無重疊、單欄列表、展開／收起、搜尋篩選、跳至主要內容、冰藍背景、文字對比至少4.5:1、無水平溢出、鍵盤焦點、提示及正誤狀態。另逐題核對128題的題幹及收藏不重複，搜尋題目的分題、圖形及表格數量與整卷一致，提示及批改後原題不變；亦檢查標誌載入、藍綠像素、固定尺寸、與品牌名稱無重疊及分頁圖示連結，並比較列印樣式的顏色及尺寸與原配色一致。最新內部檢視截圖位於 `tmp/single-question-20261015/`，不包含在發佈包內。
